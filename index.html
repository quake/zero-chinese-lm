分级验证损失 检验是否遗忘已学过的简单规律

每个级别使用独立的验证文本（不参与训练），橙色虚线是课程阶段的分界。 阶段 1 只采样启蒙语料，此时其它级别的损失往往会暂时升高——模型只学会了简单句子的分布，对复杂文本变得过分自信； 进入下一阶段后通常会回落。这正是课程学习里要观察的“遗忘 / 过拟合”现象。

    术语说明 给第一次接触的人

    Loss / Token / Attention / Embedding / Curriculum / Checkpoint

    Token：模型处理的最小单位。这里是单个汉字或标点。词表（Vocab）是模型认识的全部字符。

    Loss：损失，衡量模型预测下一个字有多“意外”。随机猜时约等于 log(词表大小)，越小越好。

    Validation Loss：在没参与训练的文本上算出的损失，用来判断模型是真的学会了，还是只背下了训练文本。

    Attention：注意力。模型在预测下一个字时，会按权重去看前面出现过的字。Heatmap 里每行就是一次“看”的分配。

    Embedding：把每个汉字变成一串数字向量。意思或用法相近的字，向量往往也更接近。

    Curriculum：课程学习。先用简单语料训练，再逐渐混入更难的语料，和人的学习顺序类似。

    Checkpoint：训练进度存档，包含权重、优化器状态、随机数状态和课程设置，可以完整恢复。

    关于真实性：页面中的每一个数字、曲线、Attention 权重和生成的汉字，都来自浏览器里这个从随机参数开始训练的小模型， 没有任何预置结果。默认教学版只有约 18 万参数、约 18 万字语料（公版现代文 + 维基百科抽样），它学到的是汉字与常见字词的统计规律， 不能达到真正学生那样的语言能力；“启蒙 / 小学 / 初中 / 高中”只表示训练语料的难度。
